# Samantha Makowski — IT Portfolio

Live: https://samantha-portfolio-pdg5.onrender.com

A full stack portfolio built in React and Vite with two Node and Express backend servers.

---

## Stack

- React, Vite, CSS3
- Node.js, Express.js
- Anthropic API (Claude Haiku)
- EmailJS
- Render

---

## Running locally

You need three terminal tabs.

**Frontend**
```bash
cd client
npm install
npm run dev
```

**Analytics server**
```bash
cd BE/analytics-server
npm install
node server.js
```

**Resume tracker**
```bash
cd BE/resumetracker
npm install
node server.js
```
